# 🎓 Campus Placement Analytics Dashboard

## 📌 Project Description
This project presents an interactive Campus Placement Analytics Dashboard created to evaluate student placement trends, academic performance correlates, technical/soft skill impacts, and employer hiring outcomes across academic years. The dashboard provides a clear and comprehensive summary of institutional performance to support data-driven decision-making.

## 🎯 Objectives
- Analyze total students, placed students, placement percentage, and unplaced counts
- Understand recruitment trends across academic years, engineering branches, and gender demographics
- Track academic benchmarks through cumulative grade point averages (CGPA)
- Evaluate the impact of hands-on projects, corporate internships, and technical/soft skill proficiencies
- Identify top-performing academic branches and high-demand corporate recruiters

## 📊 Tools & Technologies Used
- Power BI Desktop  
- Power Query & Data Modeling (DAX Measures)  
- Exploratory Data Analysis (EDA)  
- Multi-Page Dashboard Design & Visual Analytics  

## 🗂 Dataset Details
The dataset contains student records and recruitment outcomes, including the following fields:
- Student ID  
- Gender  
- Branch (Civil, CSE, ECE, Electrical, IT, Mechanical)  
- CGPA (Cumulative Grade Point Average)  
- Projects (Total hands-on projects completed)  
- Internships (Number of corporate internships undertaken)  
- Technical Skills (Python, SQL, Machine Learning, Data Science, Java, C++)  
- Soft Skills (Average, Good, Excellent, Poor)  
- Placed Company (TCS, Microsoft, Amazon, Google, Wipro, Infosys)  
- Placement Status (Placed vs. Unplaced)  

## 📈 Dashboard Features
- **KPI Cards:** Total Students, Placed Students, Placement %, Unplaced Students, Avg CGPA, Avg Projects, Avg Internships  
- **Overview Page:** Placement Distribution Donut Chart and Executive Summary KPIs  
- **Academic Performance Page:** Average CGPA by Branch Bar Chart, Multi-Year Placement Trend Line Chart, and Branch-wise Placement Contribution  
- **Skills & Internships Page:** Technical Skills vs. Placement Bar Chart, Soft Skills Success Matrix, and Average Internship Exposure by Branch  
- **Company Analysis Page:** Recruiter Volume Bar Chart (TCS & Microsoft Lead Campus Hiring) and Candidate-Level Detail Inspection Tables  
- **Interactive Slicers:** Year, Gender, Branch, Soft Skills, and Placed Company with dynamic cross-filtering  

## 🧹 Data Cleaning & Modeling Steps
- Checked and cleaned missing or inconsistent student records  
- Standardized categorical variables (Branch names, gender classifications, and recruiter titles)  
- Validated numerical data types (CGPA ranges, project counts, and internship frequencies)  
- Established robust relational data structures and calculated measures for dynamic aggregation  

## 🔍 Key Insights
- Achieved an overall institutional placement rate of **50%** across engineering disciplines  
- **TCS** (93 students) and **Microsoft** (72 students) emerged as the leading volume recruiters during campus hiring  
- Technical skills in **Python, Data Science, and Machine Learning** directly correlate with higher placement counts  
- Placed candidates maintain a strong academic baseline with an average CGPA of ~7.52 alongside robust project and internship exposure  

## 📌 Conclusion
The Campus Placement Analytics Dashboard offers an interactive and comprehensive view of recruitment performance. By combining executive KPIs, specialized multi-page charts, and dynamic slicers, it enables stakeholders to monitor trends, analyze high-demand skills, evaluate recruiter distributions, and make informed decisions to improve student placement outcomes.
